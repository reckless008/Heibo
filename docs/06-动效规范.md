# 动效规范

Heibo 的动效基准。对齐苹果 HIG 的转场原则：**节奏统一、与行程无关、跟手 1:1**。
本文档的参数即代码里的真实取值；改动画先改这里、再改代码，保持文档与实现一致。

## 总则

1. **同一族弹簧**：页面打开 / 返回 / 图片缩放共用 HIG 弹簧族，行程长短只影响路径、不影响速度感
   ——「返回到屏幕正中显得快」这类不一致是不允许的。按**有无动量**分两档：
   无动量（按钮返回、普通打开）`HigTransition`（damping 1.0，不回弹）；
   带动量（手势甩动释放）`HigTransitionFling`（damping 0.8，轻微回弹）。
2. **手势跟手 1:1**：任何跟手动画不得插补间（补间会让帧拖在手指后面，读作拖泥带水）；
   手指停哪、画面停哪。
3. **速度交接**：手势松手瞬间，把手指速度交给弹簧初速度（`initialVelocity`），拖动与动画之间
   不留断开感；反向时同样携带速度，避免「撞墙」。
4. **动量投影**：甩动型手势按**速度**决定去向（快甩小距离也算完成），位移阈值只是慢拖的兜底。
5. **按压微交互统一**：可点元素按下缩小 0.94–0.96，回弹用低阻尼弹簧（见下表）。
6. **完成态无尾巴**：动画落点即视觉终点，不设「提前落定的死区」或补间尾巴。
7. **减弱动效**：系统「移除动画」开启时转场降级为直接落位，不播放弹簧。

## 页面转场

| 场景 | 曲线 | 说明 |
| :-- | :-- | :-- |
| 打开详情 / 主页等 | `HigTransition`（damping 1.0） | 展开路由从卡片缩略位置生长（shared-element），无动量 |
| 返回（按钮） | `HigTransition` | 收回来源卡片；完整行程，不截短 |
| 返回（手势松手补动画） | `HigTransitionFling`（damping 0.8） | 接力退场并携带手指速度（速度交接） |
| 图片打开 / 关闭 | `HigTransition` | 从缩略图位置生长、收回缩略图（横图 / 竖图 / 长图同等覆盖） |

- 展开路由的正文淡入淡出与帧同步（同一根弹簧），交叉淡出窗口：卡片在帧进度 0.55→0.10 区间渐显，
  与页面内容此消彼长，任意时刻至少有一层覆盖画面。
- 侧滑路由（非展开）同曲线，位移 + 视差（下层页面以 1/4 速反向位移）。

## 手势返回（预测性返回）

| 项 | 取值 | 说明 |
| :-- | :-- | :-- |
| 跟手映射 | 1:1 即时 | `snapTo`，无补间 |
| 落点压缩 | 无 | 帧完整映射全程，手指拖到底即卡片完全落定 |
| 判定阈值 | `LandedProgress = 0.2` | 手势被系统取消时，进度已过 20% 即直接完成返回，不回弹 |
| 松手补动画 | `HigTransitionFling` + 速度交接 | 提前松手从当前进度续上退场，初速度 = 手指速度 |

## 图片查看器

| 项 | 取值 | 说明 |
| :-- | :-- | :-- |
| 打开 / 关闭生长 | `openFrame` 映射 | 缩略图矩形 → 全屏窗口，含圆角过渡 |
| 降级路径 | 0.92→1 缩放 + 淡入 | 仅当完全取不到缩略图位置时 |
| 下滑退出阈值 | 120dp 或甩动速度 > 800dp/s | 动量投影：快甩小距离也算退出 |
| 下滑松手 | 弹簧回弹（damping 0.8）+ 速度交接 | 超阈值退出并由退场动画接力；未过阈值带速度弹回 |

## 顶栏

| 项 | 取值 | 说明 |
| :-- | :-- | :-- |
| 「我」页标题折叠 | 1:1 跟滚动 | 上滑 44dp 内渐隐上移；回滚还原 |
| 底栏 / 顶栏 tab 切换 | 220ms 线性交叉淡入 | 仅内容交叉淡出，材质只有一层 |

## 按压微交互

| 元素 | 缩放 | 曲线 |
| :-- | :-- | :-- |
| 动作小胶囊（转发/评论/点赞） | 0.94 | `spring(0.55, MediumLow)` |
| 底栏页签 | 0.96 | `FeedTabPressSpring` = `spring(1.0, 438.65)` |
| 分段指示块 / 文字 | 0.96 | `FeedTabPressSpring` |

## 分段胶囊（信息流顶栏）压扁动效

由 `CouiSegmentIndicatorMotion` 驱动（沿用 COUI 上游实现）：

| 状态 | 行为 |
| :-- | :-- |
| 点选切换 | 指示块宽度弹簧（grows: bounce 0.5 / 否则 0.3；response 0.6），切换瞬间高度压扁至 0.9 倍 |
| 横向拖动 | 指示块随手指拉宽（峰值 +14dp）、高度按 sin 曲线压至 0.9 倍，松手弹簧归位 |
| 边缘阻尼 | 首/末页切换时外溢宽度受限（maxExtraWidth 16dp） |

## 参数速查

| 参数 | 值 | 用在 |
| :-- | :-- | :-- |
| `HigTransition` | `spring(damping 1.0, stiffness 380)` | 无动量转场（打开、按钮返回） |
| `HigTransitionFling` | `spring(damping 0.8, stiffness 380)` | 带动量转场（手势松手、甩动弹回） |
| `FeedTabPressSpring` | `spring(damping 1.0, stiffness 438.65)` | 分段按压回弹 |
| 胶囊按压弹簧 | `spring(damping 0.55, stiffness MediumLow)` | 动作胶囊按压 |
| 图片甩动速度阈值 | 800dp/s | 下滑退出的动量判定 |
| 转场交叉淡出窗口 | 帧进度 0.55 → 0.10 | 展开/返回的卡片与页面内容交接 |
| 手势取消完成阈值 | 进度 0.2 | 预测性返回被系统取消时 |
| 下滑退出阈值 | 120dp | 图片查看器 |
| tab 切换交叉淡入 | 220ms | 主页三大页签 |

## 附：导航栏材质与排版（八条原则对齐）

- **材质分量 = 表面积**（Craft/Simplicity）：大表面更强模糊——底栏宽胶囊 blur 52px、顶栏分段胶囊 44px、
  动作小胶囊 28px，尺寸层级读作材质厚度层级。
- **玻璃上的文字加实**（vibrancy 可读性）：底栏标签 11sp / Medium / +0.2 字距，不用扁平灰字。
- **底栏宽度对齐顶栏**（Familiarity：同构元素同行为同尺寸）：左右各 12dp 与顶栏同跨度，
  三项均分摊开，不再挤在中间。
- **不叠浅玻璃**（legibility）：玻璃件只叠在内容上，不叠在另一层浅色玻璃上。
- **滚动渐隐而非硬分割线**（§12）：顶栏渐变玻璃自带 24dp 向下渐隐带。
