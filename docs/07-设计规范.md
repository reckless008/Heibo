# Heibo 设计规范

Heibo 的设计基准。COUI 是原作者对 ColorOS 17 设计语言的组件库实现；Heibo 在其上叠了**自己的
设计哲学——对齐苹果 HIG（液态玻璃、流体交互）**：材质厚度产生层级、边缘光影产生区分度、
排版靠字重而非颜色、动效统一节奏。本文档的参数即代码里的真实取值；改视觉先改这里、再改代码，
保持文档与实现一致。

## 总则

1. **材质分层，而非颜色分层**：浮起的玻璃比底座「厚」——厚来自模糊半径与边缘光影，不来自更白的色块。
2. **边缘是玻璃的全部表情**：区分度来自边缘光影（受光发丝边 + 色散折射），不靠加深底色；
   底色刻意比背景只透不抢。
3. **一套语言全站同源**：导航栏、指示块、圆钮、胶囊、查看器控件共用同一套材质与边缘绘制
   （`liquidGlass` + `glassLens` / `glassEdgeLight`）；不允许一处一个画法。
4. **排版对齐 Apple HIG**：层级靠字重（选中 Medium / 未选 Regular），小字正字距，不靠变色。
5. **可用性优先**：玻璃透明度用户可调（设置 → 显示与交互）；系统「移除动画」时动效降级。
6. **明确的例外**：转发 / 评论 / 点赞小胶囊（`GlassActionPill`）不玻璃化——该处密集出现、
   需要低干扰，保持液态玻璃底 + 发丝描边的轻量形态。
7. **端头同心**：嵌在容器里的选中块，四周内缩量必须相等，端头曲率与容器同心；
   不等距内缩会让缝隙忽宽忽窄，曲率差一眼可见。

## 材质体系

### 底色与浓度

| 项 | 取值 | 说明 |
| :-- | :-- | :-- |
| `glassPlate(dark)` | 亮 `#FFFFFF` / 暗 `#141414` | 玻璃底色，接近背景但更纯净 |
| `glassPlateAlpha(dark)` | 亮 0.16 / 暗 0.26，随透明度设置缩放 | 容器级浓度（底栏、分段胶囊）；参考 Glasswork 的 6%–22% / 16%–38% 区间 |
| 透镜填充 | 亮 `#4DFFFFFF` / 暗 `#24FFFFFF` | 选中块、圆钮等「厚一档」的玻璃，仍透出背景 |
| 小胶囊浓度 | `glassPlateAlpha × 0.72` | 例外件，比导航更透 |

### 玻璃透明度（用户可调）

- 设置项 `glassAlpha`：80–140%，40 = 标准（系数 1），值越大玻璃越透。
- 映射：`glassAlphaFactor = (1.4 - glassAlpha / 100)`，钳制 0.35–1.35；
  所有玻璃件共用这一档缩放。

### 取样模糊（liquidGlass）

| 项 | 取值 | 说明 |
| :-- | :-- | :-- |
| 模糊半径 | 12px（常规）/ 16px（底栏大面） | 轻模糊保留背景颜色；旧版 44/52 会糊成白雾 |
| 饱和度 / 亮度 | 亮 1.8 / +6%，暗 1.6 / -20% | 提高饱和与亮度让玻璃取背景色，而不是靠白底 |
| 高光 | COUI `rememberGlassHighlight` | 继承组件库的受光高光 |

## 边缘光影（glassEdgeLight）

玻璃与背景的区分度来自**一条**受光边，而不是多道描边。折射是边界内侧的柔光，不是第二道轮廓。

| 层 | 取值 | 意象 |
| :-- | :-- | :-- |
| 外缘受光边 | 1dp；顶 0.95 白 → 冷 `#A8C8FF` 0.20 → 暖 `#FFD9A8` 0.16 → 底 0.06 黑（暗色各减半）。冷暖直接混在这条边的渐变里 | 单一边界 + 色散 |
| 顶部倒角 | 0.5 白 → 0，贴边 6dp（透镜 0.32，暗色减半） | 顶面受光，窄柔光 |
| 左右倒角 | 左 0.20 白 / 右 0.10 白，贴边 5dp（暗色/透镜再减） | 侧壁厚度 |
| 底缘收光 | 透明 → 0.06 黑，贴边 6dp（透镜 0.04） | 柔和底折光 |

- **选中透镜不画自己的外圈**：`glassEdgeLight(dark, lens = true)`——透镜嵌在容器玻璃里，边界由容器负责，透镜只保留填充、顶部受光和投影。容器 + 透镜各自再画一圈会读成「双层」。
- 旧版在 1.6dp 内缩处再画一道 1dp 色散线，放大看是第二圈轮廓，不像折射；已移除。
- 投影：3dp（小件 2dp），ambient 0.16 / spot 0.2 黑——只托底，不抢边缘。

### 边缘折射（rim lens）

参考 [Glasswork](https://github.com/kubai087/glasswork/blob/main/README.zh-CN.md) 的核心层：液态玻璃不是「轻模糊 + 描边」，而是**边缘把背后的画面向内弯折**。

- `liquidGlass` 在 `blur` / `colorControls` 后接一个 AGSL `RuntimeShader`（`GLASS_LENS_SHADER`）；
- 用圆角矩形 SDF 求到边缘的距离：边缘位移最大，中心为 0；采样坐标沿内法线偏移，R/B 各多/少一点形成色散；
- 参数：`rim = min(短边 × 0.42, 44dp)`，`edge = 1.1`，`power = 2.6`，`dispersion = 15%`；
- Android 13+ 生效；低版本回退到当前的单边界 + 倒角；
- 选中透镜放在容器里，折射只作用于容器玻璃（透镜自己不画边、不单独折射）。

至此材质标准为六层：投影 → 轻模糊/提饱和提亮 → **边缘折射** → 着色 → 单边界 + 倒角边光 → 墨色。

## 深色层级（Apple HIG）

深色不是把浅色调暗，而是基底 + 逐级抬升。参数：

| 层 | 色值 | 用途 |
| :-- | :-- | :-- |
| 基底 | `#000000` | 页面、列表底、消息底 |
| 卡片 | `#1C1C1E` | 信息流、评论、设置、消息卡片 |
| 浮起 | `#2C2C2E` | 选中胶囊、菜单、输入框底、分段轨道 |
| 最高 | `#3A3A3C` | 图片占位、最上层控件 |
| 分隔 | `#38383A` | 分隔线、描边 |
| 主文字 | `#FFFFFF` 92% | 标题、正文 |
| 次文字 | `#FFFFFF` 60% | 时间、辅助说明 |
| 辅助 | `#FFFFFF` 30% | 占位、禁用 |

- 浅色不变：页面 `#F0F1F2` + 纯白卡片。
- 引用/转发块 = 基底色（深色 `#000000` 落在 `#1C1C1E` 卡片上，浅色 `#F0F1F2` 落在白卡上），是卡片里的「凹陷」层，不是第二张卡。
- 顶栏/底栏玻璃在深色下透出基底黑；选中透镜用 `#2C2C2E`，比容器亮一档。
- 对比度只靠这三档文字色，不再用额外的灰块区分层级。

## 滚动边缘渐隐（scroll edge effect）

悬浮栏不再和内容硬碰：内容滚到栏下方时先淡向页面底色（Apple iOS 26 的 scroll edge effect），
栏的边缘因此始终是「干净」的。渐隐层画在页面层（`MainShell` 的 `layerBackdrop` 容器）里，
顶/底栏的玻璃取样到的也是渐隐后的画面，文字不会从胶囊里透出来。

| 位置 | 高度 | 渐变停靠点（自上而下） |
| :-- | :-- | :-- |
| 顶栏 | 状态栏 + 44dp + 4dp | 页面色 0.94 → 0.72(40%) → 0.24(75%) → 0(100%) |
| 底栏 | 52 + 18 + 64 = 134dp | 0 → 0.22(30%) → 0.66(55%) → 0.88(75%) → 0.96(100%) |

- 消息页顶栏已由 `AppBarBlurOverlay` 负责，页面层的顶栏渐隐在该页淡出（220ms），避免两层材质叠在一起。
- 渐隐是颜色层，不替代玻璃：栏内仍是 `liquidGlass` + `glassEdgeLight`，渐隐只负责内容与栏之间的过渡带。

## 排版（Apple HIG）

| 场景 | 字号 / 字重 | 字距 |
| :-- | :-- | :-- |
| 玻璃上的小字（页签标签等） | 11sp，选中 Medium / 未选 Normal | +0.2sp |
| 动作文字（胶囊计数、按钮） | 13sp Medium | 0 |
| 标题 / 正文 | 跟随 COUI 规范 | — |

原则：**层级靠字重，不靠变色**；玻璃上的文字用正常墨色（vibrancy 靠材质提亮背景，不给文字加白边）。

## 动效

见 [06-动效规范.md](06-动效规范.md)：弹簧族、跟手 1:1、速度交接、动量投影、按压微交互。
要点：路由转场统一 damping 1.0，动量只通过初速度交接（不换弹簧、不回弹）；按压缩 0.94–0.96，
减弱动效降级为直接落位。

## 与 COUI 的关系

Heibo 的视觉基准是本文档，不是 COUI：COUI 是组件底座（preference / popup / 图标 / blur 等），
材质、排版、导航与动效以 Heibo 规范为准。上游 COUI 的默认外观不再被视为「正确」，只保留其
组件能力与可及性，视觉按本规范重绘。

- **组件用 COUI，视觉用 Heibo 规范**：COUI 的圆钮 / 玻璃面（`HighlightedIconButton`、
  `couiGlassSurface`）在 Heibo 中被统一替换为本规范的玻璃体系；仅搜索栏内部取消键等
  组件内件保留 COUI 自带样式。
- **改动原则**：COUI 上游更新时，视觉差异以本文档为准做取舍——保留组件的功能与可及性，
  材质与边缘按本规范重绘。

## 维护

1. 先改文档、再改代码；参数表里的数字必须与代码常量一一对应。
2. 新增玻璃件必须复用 `liquidGlass` + `glassLens` / `glassEdgeLight`，禁止新画一套。
   例外：40dp 正圆钮用 `glassCircle`（同单边界参数，用 `drawCircle` 绘制）——`Modifier.shadow(CircleShape)`
   的 RenderNode 圆形轮廓在部分渲染器上会被近似成八边形并盖住填充，`clip = false` 也无法避免；
   圆钮因此不叠 shadow，区分度交给边缘光影。
3. 例外件（小胶囊）如需变更，先在此文档记录决策再动代码。
